The app now walks you through broker setup, the datalogger connection, first readings, inverter profiles and Home Assistant entity checks. It uses the published TCP port and waits for fresh readings from every expected inverter. Saved readings after a restart cannot complete setup. Changing a reading profile requires a new reading and clears the earlier review.

A searchable hardware catalogue in the app also supplies the [published compatibility matrix](https://github.com/Herbertmt978/HA-Growatt/blob/v0.4.0/docs/hardware-matrix.md). It separates checks on our two-inverter installation from community reports and protocol documentation. The new hardware report form helps other owners share useful results.

Update the Home Assistant app to use the guide. Existing MQTT identities, readings and history are preserved. The optional HACS companion has no behaviour changes; updating it is not required for the guide.

One of our installed inverters is owner-identified as MIN 2500TL-XH, but its firmware-to-feed pairing, the second model and both datalogger variants remain unconfirmed. This release does not qualify additional battery controls, models or firmware.

Validation: 2,961 tests on Python 3.12, 3.13 and 3.14 and the installed Linux package; lint, formatting and package builds; container checks on amd64, arm64, arm/v7 and 386; native Home Assistant migration and quiet-restart checks; and browser checks of setup completion and profile changes. The HA app is offered for amd64 and aarch64.
