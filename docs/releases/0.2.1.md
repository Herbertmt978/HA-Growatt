# HA Growatt 0.2.1

This fixes a cloud forwarding problem found while checking the 0.2.0 upgrade
against two live dataloggers. Growatt acknowledged both connections and was
reading their settings, but HA Growatt mistook the delay before a clock-setting
command for a cloud outage. Readings still reached Home Assistant through local
fallback, while forwarding to ShinePhone stopped.

The relay now waits for acknowledgements to the records it sends, without
requiring Growatt to set the clock within that same deadline. A real
disconnection or unanswered record still activates local fallback and provides
the clock locally when needed.

Existing app options, sensor identities and history are preserved. The other
0.2.0 features remain included, with experimental battery controls off by
default.
