# HA Growatt 0.3.0

Cloud forwarding can now recover automatically after an outage. While readings
continue locally, the app periodically checks for a valid Growatt heartbeat
reply. Once the cloud responds and local commands have finished, it reconnects
the datalogger. Failed checks back off. Set `cloud_recovery_seconds` to zero to
keep the previous reconnect behaviour.

The optional HA Growatt companion integration adds Home Assistant Repairs for a
stopped app, failed decoding and stale inverter feeds during daylight. Overnight
silence is normal; a configurable grace period allows the inverter to start
after sunrise. The companion uses the app's existing MQTT connection and does
not create another set of measurement sensors. Install it through HACS as an
Integration, restart Home Assistant, then add HA Growatt in Devices & services.

The app page refreshes its connection checks automatically without replacing
unsaved form edits. Diagnostics distinguish announcement warnings from failed
measurements. An optional ten-minute support capture records packet sizes and
decode outcomes, excluding packet bodies, serial numbers and household readings.

You can record each inverter's exact model and firmware in its existing Home
Assistant device. A read-only firmware query is available for inverters that
answer the documented registers. Unknown details remain unknown. Settings
refresh is configurable, including manual-only operation.

Other additions include buffered-reading events for automations and a previewed,
explicitly confirmed history-adoption action for unused historical entity IDs.
That action preserves historical rows and checks ownership, units and counter
type. It does not merge two histories. Read the
[feature guide](../home-assistant-features.md) before using it.

Existing sensor identities, units, MQTT formats and saved-reading recovery are
preserved. Experimental battery controls remain off by default. Protocol and
Home Assistant tests cover those controls; this release does not add physical
verification of battery models or claim support for session-key encrypted
dataloggers.

Checked on Python 3.12, 3.13 and 3.14, Linux, and all four supported image
platforms. Native Home Assistant checks cover Repairs, migration, MQTT reload,
buffered events and quiet restarts. Live installation checks are recorded
separately from synthetic control tests.
