      Battery schedules

      SPH/SPA schedules are experimental. Enable experimental controls in the app configuration, select the matching control profile above, then read a slot before changing it. Times use the inverter’s clock and may cross midnight.

      Help with a problem

      The diagnostics file contains app version, profiles, connection status and error counters. It excludes serial numbers, network addresses, credentials, readings and raw packets.

      Download diagnostics

      For an intermittent problem, collect up to ten minutes of packet summaries. The file includes packet sizes, protocols and decode outcomes. It contains no serial numbers, payloads or household readings.
